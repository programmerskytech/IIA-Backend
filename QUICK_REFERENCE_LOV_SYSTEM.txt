🎯 HOW IT WORKS:

1. Admin opens LOV Management page
   ↓
2. Selects form (e.g., "Indent Creation") and field (e.g., "Consignee Location")
   ↓
3. Adds new value (e.g., "Pune")
   ↓
4. Clicks Save → Backend saves to database and clears cache
   ↓
5. User opens Indent Creation form
   ↓
6. Frontend calls: GET /api/lov/IndentCreation/consigneeLocation
   ↓
7. Backend returns all locations including "Pune"
   ↓
8. Dropdown shows new value ✅
