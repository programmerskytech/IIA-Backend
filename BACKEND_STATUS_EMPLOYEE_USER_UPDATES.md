**Logic in UserServiceImpl:**
```java
List<String> rolesToAssign = new ArrayList<>();
if (userDto.getRoleNames() != null && !userDto.getRoleNames().isEmpty()) {
    rolesToAssign = userDto.getRoleNames();  // Use array if provided
} else if (userDto.getRoleName() != null && !userDto.getRoleName().trim().isEmpty()) {
    rolesToAssign.add(userDto.getRoleName());  // Use single role if provided
}

// Save role names as comma-separated string
String rolesAsString = String.join(",", rolesToAssign);
userMaster.setRoleName(rolesAsString);
```

**Impact:**
- ✅ Frontend can send either:
  - `"roleName": "Indent Creator"` (single role)
  - `"roleNames": ["Indent Creator", "Approver", "Admin"]` (multiple roles)
- ✅ Backend stores as comma-separated: `"Indent Creator,Approver,Admin"`
- ✅ Backend creates entries in `user_role_master` for each role

```

email            | Email address

employeeId (FK)  | Links to employee (optional)

createdBy        | Admin username
createdDate      | Timestamp

```

createdBy        | Admin username
createdDate      | Timestamp
