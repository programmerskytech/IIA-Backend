HOW IT WORKS:
Instead of hardcoded dropdown values, you'll call this API:
GET http://localhost:8081/astro-service/api/lov/{formName}/{fieldName}

Example: GET /api/lov/IndentCreation/consigneeLocation
Returns: [{ "lovId": 1, "value": "MUMBAI", "displayValue": "Mumbai" }, ...]

MAGIC: When you add values from Admin Panel → LOV Management, they automatically appear in form dropdowns!
