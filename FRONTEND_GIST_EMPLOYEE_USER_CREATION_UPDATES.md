## 2. USER CREATION PAGE

### **Current API (Already Working):**

**Endpoint:** `POST /api/userMaster`

**Request Payload (Multiple Roles Supported):**
```json
{
  "userName": "Mohit81",
  "email": "ritwiksinghkkc@gmail.com",
  "password": "Skrossi@8181",
  "mobileNumber": "9123456789",
  "employeeId": "E1114",  // ✅ OPTIONAL - can be null or omitted
  "roleNames": ["Indent Creator", "Approver", "Admin"],  // ✅ Multiple roles supported!
  "createdBy": "admin"
}
```

**Note:** Backend supports BOTH:
- Single role: `"roleName": "Indent Creator"` (backward compatibility)
- Multiple roles: `"roleNames": ["Indent Creator", "Approver"]` (new feature)

**Response:**
```json
{
  "responseStatus": {
    "statusCode": 0,
    "message": null
  },
  "responseData": {
    "userId": 83,  // ← Auto-generated by backend
    "password": null,  // Password never returned for security
    "userName": "Mohit81",
    "email": "ritwiksinghkkc@gmail.com",
    "mobileNumber": "9123456789",
    "employeeId": "E1114",
    "roleName": "Indent Creator,Approver,Admin",  // Comma-separated roles
    "createdBy": "admin",
    "createdDate": "2025-12-20T21:28:32.567495"
  }
}
```

---

### **Frontend Implementation:**

#### **1. Employee ID Field - Make Optional:**

```jsx
<TextField
  name="employeeId"
  label="Employee ID (Optional)"
  value={formData.employeeId || ''}
  onChange={handleChange}
  fullWidth
  helperText="Link this user to an existing employee (leave empty if not applicable)"
  // ❌ NO required={true}
  // ❌ NO asterisk (*)
/>
```

#### **2. Multiple Roles Selection - Use Autocomplete:**

```jsx
import { Autocomplete, Chip } from '@mui/material';

const [availableRoles, setAvailableRoles] = useState([
  'Indent Creator',
  'Approver',
  'Admin',
  'Viewer',
  'Finance Manager',
  // ... fetch from API: GET /api/employee-department-master/roles
]);

const [selectedRoles, setSelectedRoles] = useState([]);

<Autocomplete
  multiple
  options={availableRoles}
  value={selectedRoles}
  onChange={(event, newValue) => {
    setSelectedRoles(newValue);
  }}
  renderInput={(params) => (
    <TextField
      {...params}
      label="Select Roles"
      placeholder="Choose one or more roles"
      required
    />
  )}
  renderTags={(value, getTagProps) =>
    value.map((option, index) => (
      <Chip
        label={option}
        {...getTagProps({ index })}
        color="primary"
        variant="outlined"
      />
    ))
  }
/>
```

#### **3. Handle Form Submission:**

```javascript
const handleSubmit = async (e) => {
  e.preventDefault();

  try {
    const payload = {
      userName: formData.userName,
      email: formData.email,

    };

  }

```
